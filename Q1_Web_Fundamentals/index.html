1. Internet Overview

The Internet is a global network of interconnected computers and devices that communicate with each other using standard communication protocols.

Key Characteristics

  • Global connectivity
  • Information sharing
  • Communication
  • Online services

2. Fundamental Computer Network Concepts

A computer network is a collection of connected devices that communicate and share resources.

LAN

Local Area Network used within a limited geographical area.

WAN

Wide Area Network connecting devices over large geographical areas.

IP Address

A unique address used to identify a device on a network.

Protocol

A set of rules used for communication between devices.

4. Domain Name

A domain name is a human-readable address used to access a website.

www example .com

Domain names are easier for humans to remember than numerical IP addresses.

5. Web Browsers and Web Servers

Web Browser

A web browser is software used to access and display websites.

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge

Web Server

A web server receives requests from clients and sends the required web resources.

  • Apache
  • Nginx
  • Node.js
